# חיבור WhatsApp Business לעוזר האירוע

- **נפתח:** 2026-11-03, Claude Code
- **סטטוס:** פתוח (מחוץ ל-MVP)

רונן ורונית ביקשו שהוואטסאפ יתעדכן בטבלאות הלקוחות (`אפיון הבעיה ומציאת פתרונות.txt`, רונן 3 ורונית 2).
ב-MVP הסוכן זמין בתוך האפליקציה בלבד (`src/lib/agent.ts`).

**מה צריך:** חשבון Meta WhatsApp Business Cloud API, מספר מאומת ותבניות הודעה מאושרות.
**איך לחבר:** Webhook חדש (`/api/whatsapp`) שמזהה לקוח לפי מספר טלפון (`profiles.phones`), מוצא את האירוע הקרוב שלו,
וקורא ל-`runAgent` עם אותם כלים. התשובה נשלחת חזרה דרך ה-API של Meta.
