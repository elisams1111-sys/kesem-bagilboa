# קסם בגלבוע: מערכת ניהול אירועים

פרויקט גמר, קורס Vibe Coding. מקרה 1 מבנק הבעיות: «אולמי וגני אירועים – קסם בגלבוע».
המערכת מחליפה מחברות, וואטסאפים ודפים מודפסים בתיק אירוע דיגיטלי אחד. הלקוח, אנשי המכירות, מנהלת האירועים
והשף עובדים מאותו תיק, וכל שינוי מגיע אוטומטית למי שצריך לדעת עליו.

- **אפיון מלא** (בעיה, 5W1H, מסע משתמש, מסד נתונים, הרשאות, מסכים, סוכן): [docs/spec.md](docs/spec.md)
- **פריסה ל-Supabase ול-Vercel:** [docs/deploy.md](docs/deploy.md)
- **טכנולוגיה:** Next.js 16, TypeScript, Tailwind 4, Supabase (Postgres, Auth, RLS), Vercel (אירוח ו-Cron), Claude Opus 5.5 (הסוכן)

## מה יש במערכת

| למי | מה |
|---|---|
| לקוח | הרשמה, אשף הזמנה בשלבים לפי תרשים הזרימה (יומן זמינות, תפריט טעימות בחמישה שלבים, תאריך ושעת טעימה), תיק אירוע לעריכה, עוזר AI, היסטוריית שינויים |
| מכירות | דשבורד אירועים, פתיחת אירוע ללקוח עם בדיקת זמינות |
| מנהלת אירועים | כל התיקים, יומן שינויים, תור «דורש טיפול», דואר יוצא, סיכום שינויים יומי במייל |
| שף | מסך מטבח עם חישוב כמויות בשר, עוף, דגים וירקות, ניהול שעות טעימה, מייל 5 ימים לפני כל אירוע |
| מנהל כללי | הכל, ובנוסף ניהול משתמשים ותפקידים ומייל על כל אירוע שנסגר ובבוקר האירוע |

## הרצה מקומית

דרישות: Node 24 ופרויקט Supabase (ראו [docs/deploy.md](docs/deploy.md), שלב 1).

```bash
npm install
cp .env.example .env.local   # ממלאים את הערכים מ-Supabase
npm run seed                 # נתוני דמו (לא חובה)
npm run dev                  # http://localhost:3000
```

מה רואים כשזה עובד: דף נחיתה ירוק-זהב עם הכותרת «כל האירוע שלכם». אחרי התחברות, כל תפקיד מגיע למסך שלו.

## בדיקות

```bash
npm test                                          # כל הבדיקות
node --test --test-name-pattern="500" "tests/**/*.test.*"   # בדיקה אחת לפי שם
```

- `tests/logic.test.ts`: חישוב כמויות לשף, בדיקות הטופס, תאריכים והגבלת זמן באשף.
- `tests/db.test.mjs`: המיגרציות על Postgres אמיתי בזיכרון (PGlite), כולל ההרשאות: לקוח לא רואה אירוע של
  לקוח אחר, אי אפשר להזמין משבצת פעמיים, השף לא עורך, לקוח לא משנה תפקיד, ועוד.

## מבנה

```text
src/app/            דפים ונתיבי API (Next.js App Router)
src/components/     רכיבי ממשק, כולל event/ לתיק האירוע
src/lib/            לוגיקה: quantities (כמויות לשף), validation, dates, agent (סוכן AI), jobs (Cron), notify (מיילים)
supabase/migrations סכמה, RLS, טריגרים ונתוני תפריטים
scripts/seed-demo   נתוני דמו
tests/              בדיקות (node --test)
docs/               אפיון ומדריך פריסה
progress/, issues/  יומן משימות ובעיות פתוחות
```
